# be_ai Parity Matrix

This matrix tracks the Quake III / Gladiator `be_ai_*` exports against the in-repo `src/botlib/ai*` implementations to surface missing or divergent behaviour.

The chat rows that refer to a stand-state proxy were written before the current
game-side scheduler reconstruction. Stand is now one node in the retail
50-switch loop alongside the recovered goal and battle nodes; the remaining
tracked divergence is the safe handling of malformed constructor input, not an
absent general AI-node graph.
