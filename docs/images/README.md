# Logo assets

| File | Size | Use |
| --- | --- | --- |
| `logo-header.png` | 1600×433 | README header — transparent, reads on light and dark |

The wordmark follows Mr Elusive's original design — deep blue tongues over
Times-style serif letterforms with blue-white cores — redrawn rather than
upscaled from the 1999 GIF. The file here is cut out to transparency and
trimmed to its alpha bounds with a small margin, then scaled to 1600px wide.

A blue wordmark with white cores holds up on both a white and a dark page, so
the README shows it with a plain `<img>` rather than switching variants on
`prefers-color-scheme`.

There is no social-preview image. To set one, upload any 1280×640 PNG under
Settings → General → Social preview.
